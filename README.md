# gregory-bondarenko.ru

Персональный сайт-визитка аналитика данных. Опыт работы, стек, соревнования, сертификаты, резюме в PDF на русском и английском.

**Открыть:** [gregory-bondarenko.ru](https://gregory-bondarenko.ru), английская версия: [gregory-bondarenko.ru/en](https://gregory-bondarenko.ru/en/)

## О проекте

Одностраничный сайт без фреймворков и сборщиков: HTML, CSS и JavaScript в одном файле, изображения вынесены отдельно. Сама страница весит около 90 КБ, шрифты лежат рядом и подгружаются без обращения к внешним сервисам, а сканы сертификатов в WebP подгружаются, только когда до них доходит прокрутка или курсор.

Визуальная идея построена вокруг фонового графика временного ряда: он дорисовывается по мере прокрутки, точки проступают одна за другой, поверх идёт линия скользящего среднего. Ряд сгенерирован по стандартной декомпозиции (тренд, сезонность, случайное блуждание, шум), скользящее среднее посчитано окном в 15 наблюдений.

## Что внутри

- Русская и английская версии по отдельным адресам, связанные через `hreflang`, у каждой свои мета-теги, превью и резюме
- Фоновый график, привязанный к прогрессу прокрутки
- Просмотр сертификатов и дипломов во всплывающем окне с предзагрузкой
- Сворачиваемые блоки с подробностями по местам работы
- Разметка Schema.org (Person), Open Graph, Twitter Card
- Поддержка `prefers-reduced-motion`, навигация с клавиатуры, skip-link

## Структура

```
index.html      сайт целиком: разметка, стили, скрипты
cv.pdf          резюме в PDF
cv-en.pdf       резюме на английском
en/index.html   английская версия, собирается из index.html
tools/          скрипт сборки английской версии
img/            фотографии и сканы сертификатов
fonts/          шрифты в woff2 (кириллица и латиница) и их лицензии OFL
favicon.ico     иконка вкладки
og-preview.png  превью для мессенджеров и соцсетей
og-preview-en.png превью английской версии
CNAME           привязка домена к GitHub Pages
robots.txt      правила обхода для поисковых роботов
sitemap.xml     карта сайта
404.html        страница ошибки
```

## Английская версия

Источник текстов один: `index.html`. Английский вариант каждой строки лежит в её атрибуте `data-en`. После правок английская страница пересобирается командой:

```
python tools/build-en.py
```

Скрипт подставляет английские тексты, меняет мета-теги и пути, а если на странице остался русский текст, останавливается и показывает, где именно.

## Как развернуть

Сайт работает на GitHub Pages: любой коммит в `main` публикуется автоматически. Для локального просмотра достаточно открыть `index.html` в браузере, сборка не нужна.

## Стек

Vanilla JS, CSS Custom Properties, SVG. Шрифты Spectral, Golos Text и JetBrains Mono хранятся в репозитории, урезаны до кириллицы и латиницы.
