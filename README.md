# gregory-bondarenko.ru

Персональный сайт-визитка аналитика данных. Опыт работы, стек, соревнования, сертификаты, резюме в PDF.

**Открыть:** [gregory-bondarenko.ru](https://gregory-bondarenko.ru)

## О проекте

Одностраничный сайт без фреймворков и сборщиков: HTML, CSS и JavaScript в одном файле, изображения вынесены отдельно. Так страница грузится за 78 КБ, а картинки подтягиваются только когда их открывают.

Визуальная идея построена вокруг фонового графика временного ряда: он дорисовывается по мере прокрутки, точки проступают одна за другой, поверх идёт линия скользящего среднего. Ряд сгенерирован по стандартной декомпозиции (тренд, сезонность, случайное блуждание, шум), скользящее среднее посчитано окном в 15 наблюдений.

## Что внутри

- Двуязычный интерфейс с переключением на лету, включая `title` и `description`
- Фоновый график, привязанный к прогрессу прокрутки
- Просмотр сертификатов и дипломов во всплывающем окне с предзагрузкой
- Сворачиваемые блоки с подробностями по местам работы
- Разметка Schema.org (Person), Open Graph, Twitter Card
- Поддержка `prefers-reduced-motion`, навигация с клавиатуры, skip-link

## Структура

```
index.html      сайт целиком: разметка, стили, скрипты
cv.pdf          резюме в PDF
img/            фотографии и сканы сертификатов
favicon.ico     иконка вкладки
og-preview.png  превью для мессенджеров и соцсетей
CNAME           привязка домена к GitHub Pages
robots.txt      правила обхода для поисковых роботов
sitemap.xml     карта сайта
404.html        страница ошибки
```

## Как развернуть

Сайт работает на GitHub Pages: любой коммит в `main` публикуется автоматически. Для локального просмотра достаточно открыть `index.html` в браузере, сборка не нужна.

## Стек

Vanilla JS, CSS Custom Properties, SVG. Шрифты Spectral, Golos Text и JetBrains Mono подключаются с Google Fonts.
